# cannibal rules

- [URL Pattern Cannibalization: When Two Slugs Are the Same Words Reordered](./url-pattern.md): cannibal/url-pattern splits each URL's last slug on hyphens, sorts the tokens, and flags at info severity any two pages in the same directory whose sorted token sets match exactly, the reordered-slug keyword cannibalization Google has resolved by collapsing competing URLs to one canonical result since well before its March 2026 core update.
